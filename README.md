Flipper (name and repo will change) is a study tool that helps the user understand, remember, and recall information. 

### NOTE ### - 
  While the flow of the project is in place and works, it requires additional setup after cloning. (e.g. setting up the database)
  
Intended use: The user refers to their course notes to define questions and answers *in there own words*, solidifying their understanding of the material. The user is then able to take a multiple choice test on the *validated* questions and answers they submitted; where validated questions are those that are associated with false answers generated by an LLM.
